# 🚀 Day 36 — DSA Challenge

## 🧩 Problem Solved

**LeetCode 389 — Find the Difference**

### 📌 Problem Statement

Given two strings `s` and `t`, string `t` is generated by randomly shuffling the characters of `s` and then adding **one extra character**.

Return the extra character that was added to `t`.

### 💡 Approach

I used the **XOR (Bitwise Exclusive OR)** operation.

The key XOR properties are:

```text
x ^ x = 0
x ^ 0 = x
```

Since every character from `s` also appears in `t`, XOR-ing the corresponding characters causes all matching characters to cancel each other out.

The only character left is the extra character.

I converted each character to a value from `0` to `25` using:

```cpp
character - 'a'
```

After performing XOR on the values, I converted the result back into a character using:

```cpp
'a' + res
```

### 🔍 Example

```text
s = "abcd"
t = "abcde"

XOR all characters:

a ^ b ^ c ^ d
^ a ^ b ^ c ^ d ^ e

Matching characters cancel:

a ^ a = 0
b ^ b = 0
c ^ c = 0
d ^ d = 0

Remaining character = e
```

Therefore:

```text
Output: 'e'
```

### ⏱️ Complexity

* **Time Complexity:** `O(n)`
* **Space Complexity:** `O(1)`

### 🧠 Key Takeaway

This problem reinforced the **XOR cancellation pattern**.

Instead of using a frequency array or hash map, XOR allows matching characters to cancel each other, leaving only the character that appears an extra time.

More importantly, I was able to **recognize and apply the XOR technique from a previous problem to a new problem**.
